# Evidências geradas

`screenshots/` guarda capturas versionadas usadas na auditoria visual e no PDF. A pasta `before/`
preserva somente comparações relevantes da interface anterior.

`screenshots/interpreta-tablet-diagnostic-1080x2400.png` registra a inspeção visual do diagnóstico
adulto de compatibilidade da versão 0.11.

`screenshots/reading-pack-5-closure-1080x2400.png` registra o fechamento auditado da missão de
comparação de fontes na versão 0.12.

DOCX, PDFs intermediários, renderizações e arquivos temporários são reproduzíveis e não devem ser
versionados aqui. Os artefatos finais pertencem exclusivamente a `../dist/`.
